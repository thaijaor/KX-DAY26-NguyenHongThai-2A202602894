QUẢN LÝ SERVER VÀ CỔNG
- Weather MCP: http://localhost:8085/mcp, khởi động bằng python run_lab.py weather-server.
- ADK web: http://localhost:8000, khởi động bằng python run_lab.py adk-web; chọn weather_agent.
- Auth MCP: http://localhost:8000/mcp, khởi động bằng python run_lab.py auth-server.
- Auth server và ADK web dùng cùng cổng 8000, không chạy đồng thời. Weather server 8085 có thể chạy xuyên suốt.
- Khi bàn giao, Weather MCP và ADK web được để chạy; auth server đã dừng. Kiểm tra lại trạng thái thực tế, không mặc định PID cũ còn hợp lệ. File artifacts/adk-web.pid và artifacts/weather-server.pid ghi PID launcher đã tạo. Kiểm tra command line/đường dẫn để xác nhận đúng tiến trình lab trước khi dừng tiến trình hoặc cả cây con của nó; không kill tùy tiện process khác đang dùng cổng 8000/8085.
- Bạn có thể chụp hai ảnh ADK trước, sau đó dừng ADK để chạy auth; hoặc làm thứ tự 01–04 sau khi dừng đúng ADK launcher. Tự chọn thứ tự ít gây gián đoạn nhất. Cuối cùng để Weather MCP và ADK web chạy lại nếu khả thi và báo rõ trạng thái.
